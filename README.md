# Morrel - VR Zombie Combat Experience

## Overview

Morrel is an immersive virtual reality zombie combat game developed as a comprehensive VR project. The game challenges players to survive and combat waves of zombies in an intense, action-packed environment using realistic VR interactions and mechanics.

## Project Description

This project represents a complete VR game development initiative, combining cutting-edge graphics technology with engaging gameplay mechanics. Players are placed in a first-person perspective where they must utilize various weapons and strategies to defend against hordes of undead enemies. The experience emphasizes immersion, responsive controls, and dynamic combat scenarios.

### Key Features

- **Immersive VR Gameplay**: Full first-person perspective combat experience optimized for VR headsets
- **Zombie AI System**: Intelligent enemy behavior with varied attack patterns and movement mechanics
- **Weapon Mechanics**: Multiple weapon types with distinct handling and effectiveness
- **Survival Mechanics**: Resource management and wave-based enemy progression
- **Visual Fidelity**: Advanced graphics rendering with optimized shaders for VR performance

## Technical Specifications

### Technology Stack

- **Engine**: Unity
- **Primary Languages**:
  - ShaderLab (61.4%) - Advanced graphics and visual effects
  - C# (25.9%) - Core gameplay logic and systems
  - HLSL (12.7%) - Low-level graphics programming

### Architecture

The project leverages modern graphics programming techniques with optimized shader-based rendering to maintain high performance in VR environments, critical for preventing motion sickness and ensuring smooth user experience.

## Getting Started

### Requirements

- Unity (version compatible with project)
- VR development environment setup
- Target VR headset SDK (e.g., Meta Quest, SteamVR, etc.)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Christophe-Le-Bellego/Morrel-Christophe-Projet-VR.git
   ```

2. Open the project in Unity

3. Install required VR plugins and SDKs for your target platform

4. Build and deploy to your VR headset
